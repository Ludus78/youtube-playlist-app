Utilisé SUPABASE dans mon code : 
Ensuite, dans tes fichiers .ts ou .vue, tu peux accéder à ces variables comme ceci :
import { createClient } from '@supabase/supabase-js'

const config = useRuntimeConfig()

const supabase = createClient(config.public.supabaseUrl, config.public.supabaseKey)

Utilisation dans les composants :
Vous pouvez maintenant utiliser supabase dans vos composants comme suit :
const { $supabase } = useNuxtApp()

async function signInWithEmail(email, password) {
  const { user, error } = await $supabase.auth.signIn({ email, password })
  if (error) throw error
  console.log('User logged in:', user)
}


Utilisé la clé API dans mon code :
Dans un Composable (/composables)
Les composables sont parfaits pour des fonctions réutilisables, surtout dans Nuxt 3.

Créer le fichier du composable
Crée un fichier dans le dossier /composables (si le dossier n'existe pas, crée-le) :
/composables/useYouTube.js
javascript
Copier
Modifier
export const useYouTube = () => {
  const searchYouTube = async (query) => {
    const apiKey = process.env.NUXT_PUBLIC_YOUTUBE_API_KEY;
    const url = `https://www.googleapis.com/youtube/v3/search?part=snippet&q=${encodeURIComponent(query)}&key=${apiKey}&maxResults=5`;

    try {
      const response = await fetch(url);
      const data = await response.json();
      return data;
    } catch (error) {
      console.error('Erreur lors de la requête API YouTube:', error);
    }
  };

  return { searchYouTube };
};
Utiliser le composable dans un composant
Par exemple, dans un composant Vue /pages/index.vue :
vue
Copier
Modifier
<template>
  <div>
    <input v-model="query" placeholder="Rechercher une vidéo YouTube" @keyup.enter="handleSearch" />
    <ul>
      <li v-for="video in videos" :key="video.id.videoId">
        {{ video.snippet.title }}
      </li>
    </ul>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import { useYouTube } from '~/composables/useYouTube';

const { searchYouTube } = useYouTube();
const query = ref('');
const videos = ref([]);

const handleSearch = async () => {
  const result = await searchYouTube(query.value);
  videos.value = result.items;
};
</script>
